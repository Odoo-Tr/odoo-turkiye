Turkish Account Groups

The Turkish chart of accounts of Odoo 15 has no account groups, so the chart of accounts is a flat list. This module adds the 8 main groups and 56 sub-groups of the Turkish uniform chart of accounts (Tek Düzen Hesap Planı); accounts fall into their groups by code.

100 Kasa → 10 HAZIR DEĞERLER → 1 DÖNEN VARLIKLAR

Features

  • 8 main groups and 56 sub-groups, with their Turkish names.
  • Added on install to companies that use the Turkish chart; a group with the same code is kept.
  • Companies that install the Turkish chart later get the groups with it.

How to use

  1. Install the module.
  2. Accounts get their group from their code; the chart of accounts can be grouped by it.

Odoo 16 and later have these groups in the Turkish chart, so this module is for Odoo 15 only. The list comes from Odoo S.A.'s Turkish localization of Odoo 17 (LGPL-3); two groups without a name there were named and a typo was fixed.

Compatibility and support

Odoo 15.0 (tested on Community). Depends only on l10n_tr. No external service is used. Licensed under LGPL-3. Questions and bug reports: destek@odoo-tr.com

Türkçe açıklama

Odoo 15'in Türkiye hesap planında olmayan hesap gruplarını ekler: Tek Düzen Hesap Planı'nın 8 ana ve 56 alt grubu.

  • Kurulumda Türkiye planını kullanan şirketlere eklenir; aynı kodlu grup varsa atlanır.
  • Hesaplar koduna göre gruplarına kendiliğinden yerleşir.
